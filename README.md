## 功能清单

### 基础编辑

新建 / 打开 / 保存 / 另存为 / 撤销 / 重做 / 剪切 / 复制 / 粘贴 / 全选 / 查找 / 替换 / 转到行 / 插入日期 / 自动换行 / 字体 / 缩放(30%\~500%) / 打印 / 拖放打开 / 状态栏

### 转换菜单（7 个子菜单分类）

* **大小写/命名** — 大写、小写、Title、Sentence、camelCase、PascalCase、snake\_case、kebab-case、SCREAMING\_SNAKE
* **行处理** — 去多余空格、删空行、去首尾空格、加/去行号、Tab↔空格、排序、反转、打乱、去重
* **编码/解码** — Base64、URL、HTML、Unicode（各含编码+解码）
* **哈希** — MD5、SHA-1、SHA-256、SHA-512
* **格式化** — JSON格式化/压缩、XML格式化、SQL格式化、CSV对齐
* **代码转换** — 转C#字符串、转Python字符串
* **批量操作** — 加前缀、加后缀、移除前N字符、移除后N字符
* **换行符** — CRLF / LF / CR 互转

### 强力加密

* **密码加密** — PBKDF2-HMAC-SHA256 (10万次迭代) + AES-256-CBC，文件头 `MTEP` 魔数
* **MTEP 密钥文件** — 256-bit 随机主密钥 + HMAC-SHA256 完整性校验，加密文件和 `.mtepkey` 密钥文件分离，缺一不可

### 界面

* 极简黑白双主题（一键切换）
* 中英文双语（Help→语言 即时切换，无需重启）
* 多标签页（ttk.Notebook）
* 状态栏实时统计（字符/单词/行/光标位置/缩放）
* Ctrl+滚轮缩放

## 技术规格

* Python 3.8+ / Tkinter + ttk
* 依赖：`cryptography`
* 单文件 `mytext.pyw`，零其他依赖
* 支持 UTF-8 / UTF-16 / GBK 自动检测
